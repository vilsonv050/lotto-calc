# NLOTO Local App

Отдельное локальное приложение для «Статистики тиражей v7.7». Страница
`nloto.ru` для его работы не нужна.

## Запуск

1. Дважды щёлкните `START_NLOTO_APP.cmd`.
2. Браузер автоматически откроет адрес `http://127.0.0.1:8787`.
3. Если приложение уже запущено, повторный запуск просто откроет его ещё раз.

Для остановки используйте кнопку в приложении или
`STOP_NLOTO_APP.cmd`.

## Как это устроено

- Устанавливать Python, Node.js и другие программы не требуется.
- Локальный сервер работает средствами Windows PowerShell.
- Сервер доступен только на этом компьютере через `127.0.0.1`.
- Он обращается только к разрешённым адресам официального CDN API
  Национальной лотереи.
- Версия сервера 1.1 повторно использует сетевое соединение и обрабатывает
  до восьми запросов к деталям тиражей параллельно.
- Интерфейс загружает актуальный файл
  `Scripts/Статистика Тиражей v7.7.js`.
- Для загрузки данных требуется интернет.

## Работа на другом компьютере

После синхронизации репозитория через GitHub откройте эту же папку и
запустите `START_NLOTO_APP.cmd`. В приложение и его настройки не вшиты
пути текущего компьютера.

## Если окно не открылось

Откройте PowerShell в этой папке и выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\server.ps1
```

Сообщение в окне покажет причину. Обычно нужно проверить подключение к
интернету или освободить локальный порт `8787`.
