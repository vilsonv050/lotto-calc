Версия: 2.9
  • Добавлен фильтр "Условное включение" (Если -> То) для жесткой связки чисел.
  • Добавлены фильтры "Десятки" и "Хвосты" для трендового анализа.
  • Исправлено: повторы при генерации с правилами разниц (100% уникальность).
1. Выбор лотереи
  • Восьмерки: П1 1–20, П2 1–4. Макс суммарно: 24.
  • Премьер: П1 1–20, П2 1–20. Макс: 12 в поле, 18 суммарно.
  • ТОП-12: П1 1–24. П2 нет.
2. Фильтры комбинаций Отбрасывают неподходящие билеты. Работают совместно.
  • Сумма / Разброс: точное число (75) или диапазон (75-85).
  • Чётные (3 / 3-5): количество чётных. Галочка ∑ — умный расчёт П1+П2.
  • Без соседей: запрещает числа идущие подряд (шаг +1).
  • Секторы: жёсткие квоты по диапазонам (1-10:3, 11-20:5).
  • Десятки (3-4-1): распределение: 1-9 / 10-19 / 20+. Пример: 3-4-1.
  • Хвосты (6-8): количество уникальных последних цифр. Отсекает слипшиеся комбинации.
  • Условие (Если -> То): жесткая связка. Если в билете есть число из левого поля, то ОБЯЗАНО быть число из правого. Пример: Если 4, То 5. Билеты с 4, но без 5 будут отброшены.
3. Правила разниц Позволяют задать строгую структуру комбинации по расстоянию (шагу) между числами. Формат ввода: шаг-количество. Можно комбинировать через запятую.
  • 1-3 — три пары чисел, идущих подряд. Пример: [..., 5, 6, ..., 12, 13, ...]
  • 2-2 — две пары чисел через одно. Пример: [..., 4, 6, ..., 15, 17, ...]
  • 1-2, 5-1 — две пары соседей и одна пара с шагом 5.
