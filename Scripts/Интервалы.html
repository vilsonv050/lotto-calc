Анализатор Лотерейных Архивов

Один тираж в строке, числа через запятую. Даты и ID лучше не включать; значения вне диапазона анализируемой лотереи будут отброшены.
1. Сканер Сумм
2. Сканер Чисел (Ручной)
3. Авто-сканер Чисел (Лучшие связки)
Найдет комбинации чисел, которые ВМЕСТЕ выпадали в одном тираже с самым коротким максимальным перерывом.
4. Авто-сканер Сумм (Лучшие комбинации)
5. Топ частых связок (Лотерея 1-20)
Найдет ВСЕ комбинации из N чисел (от 1 до 20), которые выпадали вместе указанное минимальное количество раз.
6. Полные повторения + Генерация 2-го поля (1-20)
Левая колонка: выделите и скопируйте готовые ставки (8 чисел + сгенерированные через запятую).
7. Полные повторения (4 из 24) + Поля 2 и 3
Архив должен содержать только первые 4 числа (от 1 до 24).
Левая колонка: выделите и скопируйте готовые ставки (4 числа + 2-е поле + 3-е поле).
8. Дубликаты полей (4 из 20 + 4 из 20)
Левая колонка: выделите и скопируйте готовые ставки (4 числа + 4 числа через запятую).
9. Кено «Цветные шары»
Механика игры: ставка содержит ровно 6 чисел от 1 до 48. Выигрышная категория зависит от хода, на котором выпало последнее из этих шести чисел.
Поддерживаются два формата: первые 6 шаров с сайта либо полные 35 шаров в порядке выпадения. Для архива из 6 шаров анализируется только 6-й ход. После расчёта можно выгрузить до 500 лучших комбинаций для «Цветные Шары Calc».
