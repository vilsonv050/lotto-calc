ЦВЕТОВЫЕ ГРУППЫ ?Цветовые группы
Клик по шарику: в билете ОБЯЗАТЕЛЬНО должно быть хотя бы 1 число из этого цвета.
Поле ввода: жесткое количество чисел. Формат: Кр:2, Син:1
?Жёсткие квоты
Точное количество чисел указанного цвета.
Сокращения: Кр, Зл, Син, Фл, Кор, Жл, Ор, Чр.
Неполная квота: Если сумма меньше П1, остаток добирается из ДРУГИХ цветов (указанные цвета исключаются).
Пример для П1=6: Кр:2, Син:1 (2 красных, 1 синий, 3 любых кроме красных и синих).
?Паттерн групп
Структура распределения чисел по цветам.
Пример: 2-2-1-1 (две группы по 2 числа, две по 1).
Сумма цифр должна равняться размеру П1!
Через запятую можно указать несколько: 2-2-1-1, 1-1-1-1-1-1

1. Выбор лотереи и Пул

  • Премьер: П1 (1–20), П2 (1–20). Макс: 12 в поле, 18 суммарно.
  • ТОП-12: П1 (1–24). П2 нет.
  • 5 из 36: П1 (1–36). П2 нет. Макс чисел: 12.
  • Цветные Шары: П1 (1–48). П2 нет. 8 цветовых групп.
  • Пул: Показывает число подходящих комбинаций. Если точное — зелёный. Если примерное — серый.
2. Алгоритмы выборки Определяют, как именно выбирать билеты из пула.
  • Классический (по умолчанию): Полный рандом. Каждый запуск — новый результат. Возможны повторы П1 в пачке.
  • Уникальный П1: Работает как Классический, но гарантирует отсутствие дубликатов Полей 1 в пачке билетов.
  • Равномерное: Делит пул на равные части, из каждой берёт 1 билет. Даёт максимальный охват.
  • Анти-пересечение: Ищет билеты с минимумом общих чисел. Идеально для сетки ставок.
  • Взвешенный: Берёт билеты, чья сумма ближе к "золотой середине" (среднее арифметическое).
  • Поток (Reservoir): Строгая математическая выборка, где у каждой комбинации равный шанс.
  • Историческая: Исключает комбинации, которые вы уже скачивали. Сброс — кнопка «Очистить».
3. Фильтры комбинаций (Поле 1) Работают совместно. Отбрасывают билеты, не подходящие под условия.
  • Сумма: Сумма всех чисел. Пример: 75 или 75-85
  • Разброс: Разница между макс. и мин. числом. Пример: 12 (узкий) или 12-16 (широкий)
  • Чётные: Количество чётных. Пример: 3-5
  • Без соседей: Запрещает пары вида (5, 6) или (19, 20).
  • Секторы: Квоты по диапазонам. Пример: 1-10:3, 11-20:5
  • Десятки: Распределение по группам: 1-9 / 10-19 / 20+. Сумма должна равняться размеру П1!
  • Хвосты: Количество уникальных последних цифр. В [2, 12, 5, 15] только 2 хвоста (2 и 5).
  • Условие (Если -> То): Жёсткая связка чисел. Если: 4, То: 5. Билеты с 4, но без 5 — отбрасываются.
4. Пакетные фильтры Анализируют всю сгенерированную пачку билетов целиком.
  • Связь N: Каждая пара соседних билетов должна иметь ровно N общих чисел.
  • Покрытие ≥: Каждое число из пула должно встретиться в пачке не менее N раз.
5. Исключения и Включения
  • Исключения: Числа, которые никогда не появятся. Пр: 5, 12
  • Включения: Числа, которые будут в каждом билете. Галочка "Случайных N" берёт из списка лишь N чисел.
  • Заморозить П1: Сохраняет П1 при генерации. Повторное нажатие "Сформировать" сгенерирует новые П2 к старым П1.
6. Правила разниц
  • Задают структуру шагов между числами в билете. Формат: шаг-количество. Комбинируются через запятую.
  • 1-3 — ровно 3 пары соседей.
  • 2-2 — ровно 2 пары через одно число.
  • Кнопка ✎ считает точное число комбинаций в пуле, подходящих под это правило.
