# Лаборатория Восьмёрок — версия 3

Полная локальная программа для лотерей «Большая 8», «Супер 8» и
«Великолепная 8»: калькулятор систем, расширенный комбогенератор,
цветовая аналитика чисел, анализ набора, слои стратегий с прогоном по
архиву, проверка билетов, архивы и версии таблиц выплат.

Большие архивы сохраняются отдельно от настроек калькулятора, поэтому
обычные действия не сериализуют десятки тысяч тиражей повторно. В разделе
анализа есть разбивка по календарным дням: частоты поля 1 и поля 2,
быстрый выбор даты и список последних дней.

Главный экран построен по рабочему сценарию калькулятора «Цветные шары»:
слева создаётся набор автоматически или вручную, справа сразу видны архив,
период проверки и кнопка расчёта. Отчёт показывает общие суммы, результат
по календарным дням и подробности каждой ставки в выбранном тираже. Внизу
экрана закреплена итоговая строка затрат, выплат и прибыли. Возле основных
команд и правил стоят значки `?` с краткими подсказками при наведении или
фокусе.

Дополнительные ограничения генератора находятся в раскрывающемся блоке.
По умолчанию все дополнительные поля пустые и фильтры выключены. Фильтр начинает
работать только после ввода значения; повторная очистка поля снова отключает его.
Пустой seed создаёт новый случайный набор при каждом запуске, а заполненный позволяет
точно повторить генерацию.
Кнопка «Очистить все» одним действием сбрасывает все дополнительные числа, ограничения,
seed и покрытие 1–20, не меняя количество ставок, размеры полей и готовый набор.
Списки включения и исключения поддерживают отдельное количество. Если количество
пустое, весь список действует жёстко: все включённые числа находятся в каждой ставке,
а все исключённые полностью отсутствуют. Если указано N, для каждой новой ставки
генератор случайно выбирает ровно N чисел из соответствующего списка. Например,
список включения `1 2 3 4 5 6 7 8` и количество `4` дают ровно четыре числа из этого
пула, а оставшиеся места заполняются по выбранной стратегии. То же правило доступно
для поля 2 с числами 1–4.
Анализ переключается между днями, числами, парами и стратегиями. Архив
разбит по схеме «год → месяц → день», как в калькуляторе «Сумма Фортуны».
Для расчёта можно выбрать весь архив, конкретный год, месяц или отдельный
день. Годы, месяцы и дни показаны отдельными уровнями без вложенной прокрутки:
выбор месяца сразу показывает компактные вкладки его дней, а выбор дня
загружает тиражи в отдельную прокручиваемую сетку.
Режимы «24» и «96 · весь день» меняют объём сетки без постраничного разрыва.
Отдельные переключатели «Рассчитать месяц» и «Рассчитать год» меняют период,
не скрывая тиражи активного дня. После импорта автоматически открывается
последний доступный день и режим 96, если в нём больше 24 тиражей. Доступны
также поиск по номеру и фильтр даты.

В слоях стратегий период задаётся отдельно перед расчётом: конкретный день, месяц,
год или весь архив. Результаты всех слоёв сравниваются на одном выбранном периоде.
Баланс периода начинается с полной суммы купленных билетов за рассчитанный период:
перед первым тиражом она показывается отдельной строкой «Старт периода», после чего
каждая строка вычитает стоимость тиража и добавляет полученный выигрыш. Чистая прибыль
и просадка рассчитываются отдельно и не подменяют остаток баланса.
История открывается постранично. Можно показывать 50, 120, 250, 500, 1 000 или 2 000
тиражей на странице и вручную переходить к первой, предыдущей, следующей и последней
странице без повторного расчёта всего периода.

## Запуск

Требуется Node.js 22.13 или новее.

```powershell
npm run dev
```

Откройте `http://127.0.0.1:4175`.

## Формат архива

CSV и TXT принимают по одному тиражу в строке:

```text
58255,20.03.2026,18,20,08,02,13,16,05,04,02
```

После номера и даты идут восемь чисел поля 1 и одно число поля 2.
В TXT вместо запятых также разрешены обычные пробелы.

## Проверка

```powershell
npm test
```

Команда собирает статическую версию в `dist` и запускает тесты расчётов,
импорта архивов и комплекта файлов сборки.
